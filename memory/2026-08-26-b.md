## The design, which is the part worth not re-litigating

**Two arrangements, and `app` is implemented ON `platform`, never beside it.** Everything the
framework does must be reachable from the library path or the library path silently becomes
second-class. `verify_52` §E renders six frames down each path and compares framebuffers byte for
byte — that check is the whole guarantee.

**The platform ADMITS SDL rather than hiding it**, and 5.1's "SDL is in the public API" residue is
now closed as a decision, not a debt. A wrapper that hides a library you have no intention of
replacing is cost with no benefit; what the class owns is *lifecycle and order*. The counter-cases
(console SDK under NDA, an existing second backend, a public API shipped to customers) are named
in the lesson so the argument is not mistaken for "we didn't think of it".

**`sandbox` keeps its loop, deliberately**, and the three reasons are in `demos/CMakeLists.txt`:
it runs three incompatible loops chosen at runtime; it is the instrument every Module 2–4
measurement came from; and somebody has to prove the library path still works. *Use the framework
when your program wants A loop; write your own when it wants THIS loop.*

## Verified facts (all read, none remembered)

The four callback signatures, `SDL_AppResult`, and — the one that decided the design —
`SDL_main_impl.h` emitting a **non-inline** `SDL_main()`. That is the ODR, which is why
`main.hpp` is one-TU-per-program and why the entry point cannot live in `libengine.a`. Also
`SDL_IterateMainCallbacks`: pump → dispatch all events → iterate, so Lesson 1.2's ordering
contract survives the inversion with SDL as its new enforcer.

## Three things that went wrong, all kept

**`iterate` had no guard at the top.** `verify_52` §D failed asserting that no frame is drawn
after `request_quit()`. SDL's own loop reads its result atom before calling iterate, so the gap
could never have appeared in a running program — but a callback should be **total**, and that
property is exactly what lets a test drive the four functions with no entry point.

**`measure_52.py` counted a comment about `SDL_Init` as a call to it.** Now strips comments first.
A measurement that counts its own footnotes is not a measurement.

**`nofold` was half a feature.** `course.js` honoured it; `course.css` never did, so a `nofold`
listing longer than the peek was clamped with no control — silently unreachable code.
Lesson 5.2 is the first page ever to use the class and `clippedWithoutToggle` caught it on the
first run. Fixed in the shared sheet.

## Traps worth remembering

- **`.reading` is where `overflow-wrap: anywhere` lives.** A Further Reading `<ul>` without the
  class turns a long URL into an unbreakable 394px token and pushes the page sideways at 390px.
  `pageScrollsX` is a bare boolean — finding the culprit needs a walk over elements whose `right`
  exceeds the viewport *and* which have no scrollable ancestor (that filter is what excludes the
  hundreds of tokens legitimately scrolled inside a `<pre>`).
- **`svgSpill`'s `overPx` can be vertical.** A caption line under the viewBox floor reports
  identically to one off the right edge.
- **Right-anchored SVG labels near x=0 spill left.** Figure 3's surface names were
  `text-anchor="end"` at x=36; anything longer than 36 units ran off the viewBox.
- Playwright is not installed here; `/Users/ishan/lab/explainers/node_modules/playwright/index.mjs`
  works as an absolute import.
