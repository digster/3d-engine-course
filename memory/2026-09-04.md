## The results

**Query, K=4, sparse relative to archetype** (n = 4 / 100 / 1k / 10k / 100k):

| | 4 | 100 | 1,000 | 10,000 | 100,000 |
|---|---|---|---|---|---|
| cheap, aligned | 0.81 | 0.91 | 1.06 | 1.26 | 1.31 |
| cheap, scrambled | 0.84 | 0.98 | 1.16 | 1.92 | **2.40** |
| real, aligned | 0.97 | 1.05 | 1.05 | 1.02 | 0.96 |
| real, scrambled | 0.98 | 1.05 | 1.05 | 1.17 | **1.34** |

**Scalar (`-fno-vectorize`), real, scrambled: 1.00 / 1.00 / 1.01 / 1.21 / 1.39.** The redirect is
**latency in the shadow of work** and costs *nothing* until the working set leaves cache **and**
the orders diverge. Either alone is free. Control: K=1 is 0.99–1.01× everywhere.

**Structural change, ns/op** — the finding is *which row moved*:

| | 4 | 100 | 1k | 10k | 100k |
|---|---|---|---|---|---|
| archetype, 4 comps | 15.4 | 15.3 | 12.3 | 15.0 | 13.1 |
| archetype, 12 comps | 29.7 | 31.4 | 40.9 | 39.0 | **58.5** |
| sparse, 4 / 12 comps | 9.6/10.1 | 9.4/10.4 | 4.5/4.6 | 5.3/4.4 | **4.25 / 4.23** |

Eight components the operation never reads take the archetype 13.1 → 58.5 and the sparse set
nowhere. Cost model is **not** bytes moved (predicts 2.3×, measured 4.5×) but **independent
memory streams touched — two per column, per move**, because a column is a separate allocation.

**Selectivity (1 in 4), real, at 100k:** lead-small 1.46 · scrambled 1.94 · lead-big 1.73 ·
**GROUPED 0.99**. **Fragmentation: 1.12× worst**, at 512 chunks of 19 — far less than folklore.
**Memory:** 25% at 4 types; 12.8 MB of index at 32 types × 1e5, ~80% of it meaning "absent".

## The decision, and why it is not the query ratio

**Sparse set.** Reasons in weight order: (1) **the migration only runs one way** — a group buys
the archetype's query later, measured 0.99× on the archetype's own best case, and the reverse
does not exist; (2) the cost accepted is bounded (≤1.94×, only above 1e4, only selective, only
ungrouped) and the cost avoided **grows with every component type the course adds**; (3) nothing
at this engine's scale is on the table anyway; (4) a quarter of the code — a tiebreaker only,
admissible *after* 1–3.

**Wrong when:** >1e4 entities, stable component sets, narrow systems (DOTS's shape). Even then
group two pools rather than rewrite.

**Refused to let `pool<T>` decide it.** 5.4's pool *is* a sparse set
(`slots_`/`items_`/`owners_` = sparse/data/dense + generations) and noticing that is worth
credit — but choosing an architecture because we own something shaped like it is choosing by
accident. Convenience: admissible as a tiebreaker, inadmissible as evidence. What it actually
lacks is **one shared id space**.

## Traps worth remembering

- **The row map must be written AFTER the re-pack.** `archetype_churn::add_material` recorded
  where the entity landed, then called `pop_row` — which patches the row of whoever swap-and-pop
  displaced, and when the moved entity was the last row that entity **is** the one being moved.
  1-in-N, silent. Found only because `verify_57` §E churns **200 frames** then walks the whole
  row map; a single-frame test passes forever.
- **`box()` strokes at full opacity and fades only the fill** (`figs_5x.py`). Fig 6 drew 32
  elements at 0.26/0.07 to show "one in four is wanted" and rendered as 32 identical outlines.
  A pattern carried by fill alone does not read; mute the **stroke** too.
- **Two adjacent SVG text runs with no space** — again (5.5 fig 6, now 5.7 fig 3:
  `"…PER COLUMN."` at x=24 ending ~x=176, next run at x=178). Only a screenshot finds it.
- **An annotation that contradicts its own caption.** Fig 3 had a dashed box around the *one*
  pool that IS in the picture, under a caption about the pools that are not. Deleted.
- **`eval(check-page.js)` returns a Promise.** `const r = eval(src); r.pass` is `undefined` and
  the MCP serializer *drops undefined keys*, so the result looks like a pass with fields missing.
  `await eval(src)`, or return it directly and let Playwright await it.
- **`figure.dia:nth-of-type(N)` counts every `<figure>` sibling**, listings included — asking for
  figure 6 gave figure 4. Use `figure.dia >> nth=N`.
- Local `playwright` is not installed; the MCP server is the browser. Screenshots must go under
  the repo root (its allowed root), so they need explicit cleanup.
