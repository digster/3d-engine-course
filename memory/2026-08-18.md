## The scope decision

STATE's plan put index buffers in 4.5; `docs/index.html` had them in 4.6. Went with STATE — the
torus port needs them or it is dishonest — and retitled 4.6 to "Uniform Data and the Matrix
Upload". No published lesson renumbered.

## The finding the lesson is built on

**Pipeline creation refuses one broken layout in six.** Pitch four short → created; four long →
created; position/normal offsets swapped → created; an attribute the shader never declares →
created. Only "a shader input nothing supplies" is refused — and that one would have been obvious
anyway, because an unfed input draws geometry stretching to infinity.

So exercise 4.4.4 became a feature. `check_layout` reads the `inputs` array from the reflection
JSON and catches three of the five. **It says which two it cannot see.**

## Three mistakes this session records

- **`line` is a reserved word in HLSL.** `const float line = smoothstep(...)` fails with
  `error: ';' : Expected` pointing at the *semicolon*, not the name.
- **I nearly destroyed STATE.md.** Wrote a fresh 233-line STATE block and replaced the file with
  it — the real block is 2,574 lines of accumulated conventions and is byte-identical to the one
  embedded in each lesson page. Caught it because the file went from 197 KB to 15 KB. `git
  checkout` and then a *merge* script instead. **STATE is append-and-merge, never rewrite.**
- **The first quantiser produced no run-length compression at all.** Quantising R, G and B
  independently across a smoothly shaded surface makes hundreds of near-identical colours, so
  Figure 3 came out at 185 KB of SVG. Snapping to a fixed palette — nearest tint by hue *first*,
  then brightness into N steps — brought it to 45 KB with a better-looking figure.
