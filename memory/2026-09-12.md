## The harness, and the measurement that was wrong before

The audit that missed this asked ONE question — "did the page file change?" — of a THREE-axis
situation: did it exit 0, did it write anything, does what it wrote match. A crashing builder writes
nothing, so eleven crashes scored as eleven passes. `check-builders.py` reports the three separately
and never infers one from another. It removes the page from the clone *first*, so a crash shows as
EMPTY rather than as the inherited copy.

Each builder runs in a **copy-on-write clone** (`cp -Rc`, APFS `clonefile`): 100 MB in ~0.1 s, so the
whole 38-builder sweep takes **10 seconds** and the working tree is never touched. `--figures` (42 s,
keeps `build/`) also regenerates the SVGs first.

## The repair, and what made it mechanical

**The rebuild diff is the oracle** — every line it prints is a correction living on the page and not
in its source. The whole job became: derive pairs from the diff, route each to whichever source
produced that line, re-run. The routing is the interesting part, because one page line has four
possible spellings:

| spelling | source |
|---|---|
| verbatim | a body fragment |
| HTML-escaped | a pinned code listing (through `esc()`) |
| re-indented | an inline SVG (the builder indents it) |
| **not a line at all** | a figure caption wrapped across Python string literals |

Tools written: `pin_listings.py` (freeze + *verify each pin against the page*), `which_commit.py`,
`fix_builder.py`, `autoport.py`, `extract_listing.py`, `extend_pins.py`.

## Findings worth carrying

- **A published page is a lossless archive of its own sources.** §8's "zero placeholders" means every
  listing is embedded whole, so when `scratch/verify_54.cpp` — gitignored, no history — turned out to
  have been rewritten by 6.4 and 6.7, its 5.4-era text was recoverable **from the page**. Six
  listings recovered this way (5.4, 5.6, 6.1, 6.2, 6.6 ×4, 6.7).

- **`html.unescape()` is not the inverse of a five-rule `esc()`.** It decodes the whole HTML5 entity
  table. Caught *only* because the extractor asserts its own round-trip.

- **Which commit to pin is decidable, not a judgement call.** The page embeds each listing escaped,
  so it is a substring test. Two pages needed a LATER lesson's commit (below) and guessing would have
  silently rewritten them.

- **The drift class recurses.** Page ← SVG ← `figs_NN.py`. Fixing only the SVG leaves the generator
  able to revert it. Found in 5.7; `--figures` is the check.

- **My own tool shipped the bug it exists to catch.** `port_line.py` treated TSV lines starting with
  `#` as comments; two of 5.1's corrections are CMake comment lines, silently dropped while the run
  reported success. Fixed by deleting the comment convention — it had no user and only a failure
  mode. Same family as `class="tag mod"`.

- **A correction can sit at any offset in a wrapped Python string.** 6.6's changed character was the
  FIRST character of a continuation line, so every fragment with leading context spanned a line
  break; 5.7's SVG label needed ZERO trailing context because the common suffix was `.</text>`.
  `autoport` now searches with context on either side and neither.

# 2026-09-12 (second session) — Lesson 6.15: Skybox and Image-Based Lighting

`next` → **6.15 shipped**. The constant `ambient` the engine has carried since 3.6 is retired in
favour of an environment map, on both renderers. 54 checks, 0 failures; golden byte-identical at
`E917C06C` for the **twenty-fourth** lesson.

## What the lesson is about, in one line each

Two things were wrong with `albedo * ambient` and only one was ever written down: **no direction**,
and **no specular half at all** — the latter on record in a shipped comment since 6.4, naming 6.15
by number. An environment map fixes both, and the same texture is the sky you see and the light you
receive.

- **The cube's geometry is where a correctness bug lives.** `dω = dA/r³`, so a corner texel is
  `1/(3√3) = 0.1925` of a centre one. Equal weights are **1.01% too bright** — and sixteen times the
  texels does not move it (1.010005 → 1.010066). A *bias*, not a discretisation error.
- **Only the diffuse half is exact.** Lambert's BRDF does not depend on `l`, so it leaves the
  integral. Second-order convergence measured, and `image_based_light` reproduces 6.2's
  `albedo × ambient` end to end to **1.291e-05** on a uniform sky. The old term is a special case.
- **The split sum's error has a shape**, measured against brute force at 1e6 samples *against the
  same cube the engine reads*: 0.08% at roughness 0.10, ≤5.8% head-on, **29.0%** at grazing,
  **73.0%** with a sun. The four-fold asymmetry *is* `n = v = r`. The sun case is a third mechanism.
  **The error depends on the environment, not only on the material** — not in the paper.
- **The roughness→mip mapping is derived**, from 6.14's closed-form lobe width, by putting both the
  lobe and the texel in steradians. The folklore is within **0.77 of a level** everywhere, and now
  has a direction: a near-mirror is *over*-blurred.

## The four bugs, and two produced plausible output

1. **ARGB vs RGBA in the BRDF table.** Hand-written shift put `scale` in blue. Green is bits 8–15 in
   both layouts so `bias` read *correctly*, and the shader's `F0*scale + bias` then reduced to `bias`
   alone — ~0 head-on, ~0.078 grazing. Not broken; **dim in a way that invited tuning.** Appeared a
   second time in the harness's unpack. Fix: `pack_argb`, which has been right since 1.6.
2. **An unconverged Monte Carlo reference.** 8,192 samples vs 1,000,000 disagree by **1.98×** with a
   6000:1 sun disc; 0.040% without it. 6.14's rule about null results **has a mirror**: check a
   non-null result has *converged*. Both are one rule — know what your instrument can see first.
3. **A seam test that measured nothing, twice.** First the probes never crossed a face; then they
   did and the answer was *still* zero, because `sky_radiance` depends only on `d.y` and is constant
   along a vertical edge. On an azimuthally-varying probe the seam is **12.09%**. *A null result
   from a fixture that cannot show the defect is a measurement of the fixture.*
4. **A build bug latent for fourteen lessons.** `engine_use_shaders` lacked a target-level edge for
   cross-directory shader files. Nobody hit it because **once a shader has been built once the file
   exists, and `make` will depend on an existing file it has no rule for** — so every earlier shader
   worked from its second build on. A clean tree would have failed on all twenty-three at once.

## check-page.js gained a rect test, and it caught this lesson's own figures

The text-on-shape check selected `line, polyline, path`, so an annotation box across a label was
invisible. Figures 1, 5 and 6 all shipped first drafts with exactly that. The new check samples the
four **edges** so "crosses" stays distinct from "contains", and is restricted to `rect[fill="none"]`
— a restriction *measured*, not assumed: over every rect it fires 26 times on 12 published pages,
nearly all labels deliberately annotating filled cells. Hollow boxes only: 9 hits on 4 pages, left
alone deliberately (same call as this morning's two pedagogical defects).
