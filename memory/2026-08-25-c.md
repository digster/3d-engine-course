## The method, which is the transferable part

**Write the falsifier first.** `--shot` was added to the pre-refactor binary before anything moved.
Then **move without changing → verify → change without moving → verify**. Relocation breaks on a
missing include; redesign breaks on a mis-ordered argument; one edit containing both leaves two
suspects. Byte-identical twice.

**The seventh frame is the lesson inside the lesson.** Six frames all reported `straddle = 0` —
the near-plane clipper was never called. Read the instrument's own counters and ask what they
missed.

## Three things that went wrong, all kept

**Two of verify_50's probes were worthless.** `correct_normal_matrix = false` reported 0 px because
4.8's theorem holds (a box's normals ARE its axes) — it needed a squashed icosahedron (454 px). And
`normals = face` reported 0 px because the stock meshes carry **no vertex normals**, so both
settings fall back to the face normal; `fell_back = 132` said so. *A measurement taken on content
that cannot express the effect is not a measurement.*

**A name collision the split created.** `enum class demo` in the sandbox's anonymous namespace
hides `namespace demo`. Renamed to `screen`. Names only collide once they can see each other.

**A default argument repeated.** Moving `draw_triangles`' declaration into a header made its
`= nullptr` defaults a redefinition. Defaults on the declaration, never on the definition.

## Also worth keeping

- **`cull_choice` is applied in two places** and verify_50 now *pins* that defect rather than
  papering over it (`cull = back, in collect only → 0 px, expected 0`). A test that asserts a known
  defect stops it becoming two. Repair is 6.5.
- **§7 lists four leftovers** and which lesson pays each. A refactor lesson that ends "and now it
  is clean" is lying.
- **One deviation from zero-placeholder**, stated in the page: the 57 moved files are a move table
  plus the exact reproducible command, not 57 near-identical listings.
- **SVG traps hit again:** `<` inside `<text>` is markup — `std::vector<raster_triangle>& out`
  rendered as `std::vector` until escaped. And an RLE panel scaled to fractional device pixels
  shows hairline seams between rows; overlapping each row by 0.6 units fixes it.
- The executable is **`build/demos/sandbox`** now, not `build/engine`. README and ARCHITECTURE
  both carry the note.
