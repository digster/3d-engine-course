## Three things that went wrong, all kept in the lesson

**The measurement took three attempts.** No floor → reported a *negative cost for adding work*. A
two-run floor → still let −541.7 ns through, because one difference is itself a noisy sample. A
five-run spread + 2× threshold + scaling the workload until the effect cleared → a real converging
per-call figure. **The convergence of two independent estimates is the evidence, not either number.**

**A comment carried since Lesson 4.3 was wrong.** It explained the buffer-setter/shader-property
asymmetry by inferring immutability as the reason, instead of reading `SDL_SetGPUBufferName`'s docs,
which say to prefer the property for buffers too. There was no asymmetry. Corrected in place, with
the wrong version quoted first. It survived four lessons and a published listing **because nothing
depends on a comment being right** — no compiler, no test, no reviewer.

**A promise from 4.5 is unpayable here.** RenderDoc has no Metal support, so the true
vertex-invocation count cannot be read on this machine. Said so, modelled it with stated
assumptions, and named the exact counter per platform. The model turned up something better than
the number would have been: reuse is a property of the index **order**.

## Also worth keeping

- **`--trace` exists because the author needed it.** A keypress-armed log cannot be tested
  headlessly; the flag that made it testable is the genuinely useful artifact (CI-diffable frame
  dump).
- **`debug_group` is not movable on purpose** — SDL's Metal rule ("pop it in the same pass") in the
  type system. On **D3D12 all three debug calls need `WinPixEventRuntime.dll`** and are *inert
  without it*: no tree, no diagnostic.
- **`SDL_gpu.h` has a page-long "Debugging" section** naming the tool per platform. It is the first
  place to look and I nearly did not.
- **HTML traps hit again:** `<strong>`/`<em>` inside SVG `<text>` spills the rest of the run (same
  as 4.8's fig6) — use `<tspan class="t-hi">`. And `check-page.js` has an `svgTextOnShape` check
  that catches labels sitting on a plotted polyline; three of mine did.
- Every earlier harness rebuilt **and** re-run: 45, 46, 47, 48 all `ALL PASS`.
